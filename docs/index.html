DockAnchor prevents the macOS dock from jumping between displays in multi-monitor setups. Anchor it to any monitor and forget about it.

Everything you need

Simple to use, powerful under the hood

🛡️

System-Level Protection

Intercepts mouse events before they reach the dock. No flashing, no restarts, completely seamless.

🖥️

Visual Display Picker

See all your monitors laid out visually. Click any display to anchor your dock there.

⚡

Profiles

Create profiles for Work, Home, and more. Auto-switch based on connected displays.

🔄

Auto-Relocate on Wake

Dock jumps after sleep? Not anymore. DockAnchor re-anchors automatically on wake and unlock.

🚀

Set It & Forget It

Launch at login, run in the background, live in the menu bar. Never think about it again.

🔒

Privacy First

No data collection. No analytics. No network calls. Fully open source and auditable.
